# 🌱 Mycelial Nursery

**The Seedbed of the System**

This is the living growth layer of Mycelial. Everything here is experimental, emergent, and meant to be nurtured into maturity before moving to other layers.

## Structure

- **seeds/** → Raw ideas, starter templates, and early-stage modules
- **mini-forest/** → Small, interconnected growing projects and experiments
- **saplings/** → Promising projects that have taken root and are ready for more attention
- **soil/** → Shared resources, patterns, and foundational nutrients
- **compost/** → Archived experiments, failed attempts, and recycled material
